# 계기판 스튜디오

촬영 영상에서 정리한 일반 경고, 주행 보조, HDP, 차로 설정을 재현한 HTML 프로젝트입니다. 총 245개 선택 항목이 들어 있습니다.

[웹에서 실행](https://www.joongyu.co.kr/cluster/) · [GitHub 저장소](https://github.com/joongyu01/cluster)

실제 차량 제어와 연결되지 않은 시각화입니다. 사진을 참고해 만든 SVG이며 제조사 공식 화면이나 원본 차량 자산이 아닙니다.

## CarrotPilot DBC 연동

상단에서 **메뉴 탐색 / DBC 조작 / 로그 재생**을 선택합니다. PC는 계기판 옆에서 조작하고, 좁은 화면에서는 계기판이 상단에 고정됩니다. **표시 확대**로 알림이나 차로를 크게 볼 수 있습니다.

**DBC 조작**에서 한국어 신호 이름과 표시값 버튼으로 효과를 확인합니다. ±1 버튼 또는 원시 값 입력 후 Enter로 적용할 수 있습니다. 바뀐 값은 계기판 아래에 표시됩니다. **신호 표 · 원시 프레임**을 펼치면 모든 값과 HEX를 볼 수 있습니다.

**로그 재생**에서 파일을 불러오고 버스·프레임을 선택합니다. 자동 재생은 1초 간격으로 다음 프레임을 보여주며 원본 타임스탬프 간격을 재현하지 않습니다. **예제 4프레임 열기**는 차선 실선→점선, HDP 아이콘, 중앙·오른쪽 경고를 바꾸는 합성 기록입니다. 실제 차량 기록이 아닙니다.

- `0x161`, `0x162`, `0x1EA`, `0x200`: CarrotPilot DBC에서 가져온 131개 신호.
- CAN 데이터 직접 입력과 candump / JSONL 파일 불러오기, 버스 선택, 프레임 이동, 이전 값 비교.
- JSONL 형식: `{"time":1.25,"bus":0,"address":353,"data":"64자리 16진수"}`. CAN FD candump 형식도 지원합니다.
- `examples/synthetic-can.jsonl`은 두 버스를 포함한 합성 파일 예제입니다.
- 파일은 브라우저 내부에서만 읽습니다. 최대 4 MB / 지원 프레임 20,000개. rlog.zst와 실시간 장치 연결은 지원하지 않습니다.
- 화면 효과를 구현하지 않은 신호는 **값만 확인**으로 표시합니다. 경고 번호 대조는 기능 매핑 확정이 아니며, 미확정 영상 데이터는 수정하지 않습니다.
- 0x161 차선 8/10의 점선은 CarrotPilot 코드 주석을 참고합니다. 위치는 영상의 시연 비율이며 실제 거리와 동일하지 않습니다. 알 수 없는 차선 값은 도형을 숨겨 표시하므로, 실차에서도 숨김이라는 뜻은 아닙니다.
- 체크섬·카운터는 검증하지 않습니다. 편집한 데이터는 CRC를 다시 계산하지 않으므로 차량 송신용으로 사용하면 안 됩니다. 사이트에는 송신 기능이 없습니다.

원본 버전과 파일 SHA256은 `src/can-schema.json`, 라이선스는 `THIRD_PARTY_NOTICES.md`에 있습니다. DBC 갱신은 `py -3 tools/import_carrot_dbc.py <CarrotPilot 저장소 경로>` 후 빌드합니다. `node check-can.cjs`로 비트 해석·로그 형식·경고 대응 범위를 검사합니다.

## 바로 실행

압축을 푼 뒤 `index.html`을 브라우저에서 열면 됩니다. 메뉴·DBC·로그 모드에는 별도 설치, 서버, 인터넷 연결이 필요하지 않습니다.

## Pilot Demo 연동

[함께 보기](https://www.joongyu.co.kr/cluster/?pilot=1) 또는 **Pilot Demo** 모드에서 개발 브랜치 설정을 계기판 옆에서 변경합니다. 테스트 칸 45 / 값 8은 왼쪽 점선, 칸 21 / 값 240→241은 중앙 경고 비교입니다. 아래 실제 데모 설정에서 바꿔도 반영됩니다.

이 모드는 인터넷과 공개 사이트 주소가 필요합니다. `ajouatom/openpilot`의 `joongyu01/carrot-wip-dev`를 Pilot Demo가 15분 주기로 확인하고, 검사 통과 후 `/dev/`와 신호 정의를 함께 갱신합니다(GitHub 실행 지연 가능). 열린 화면은 **다시 연결**하면 새 버전을 읽습니다.

현재 연결은 계기판 표시 시험 설정에 한정합니다. 지원하지 않는 칸이나 변경된 DBC 정의는 명시적으로 미반영하며, 자동 칸 순회는 지원하지 않습니다. 값 순회 -1~-4는 1/0.5/0.25/0.1초 간격입니다. 표시용 합성 프레임이며 실차 작동 확인이나 송신 기능이 아닙니다. 기존 245개 메뉴는 그대로 유지합니다.

## 코덱스에서 이어서 작업

1. `cluster-codex-project` 폴더 전체를 코덱스의 로컬 프로젝트 폴더로 엽니다.
2. `AGENTS.md`와 `HANDOFF.md`를 먼저 읽도록 요청합니다.
3. 필요한 변경을 요청합니다. 수정은 `src/`에서 하고, 결과는 `index.html`로 다시 만듭니다.

터미널용 Codex가 설치되어 있다면 이 폴더에서 `codex`를 실행하거나 `codex --cd "폴더 경로"`로 시작할 수 있습니다.

공식 프로젝트 안내: https://learn.chatgpt.com/docs/projects

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 바로 실행하는 단일 HTML 완성본 |
| `src/template.html` | 화면 구조와 SVG 계기판 도형 |
| `src/styles.css` | 디자인과 반응형 스타일 |
| `src/app.js` | 메뉴 선택, 검색, 번호 이동, 도형 변경, 자동 넘김 |
| `src/menus.json` | 245개 메뉴 데이터와 판독 주석 |
| `build.py` | 소스를 단일 HTML로 합치는 스크립트 |
| `AGENTS.md` | 후속 코딩 작업에서 보존할 기준 |
| `HANDOFF.md` | 작업 이력과 구현·검증 상태 |

## 수정 후 HTML 다시 만들기

Python 3 표준 라이브러리만 사용합니다.

Windows:

```powershell
py -3 build.py
```

macOS / Linux:

```sh
python3 build.py
```

실행하면 이 폴더의 `index.html`이 갱신됩니다. `index.html`을 직접 수정하면 다음 빌드 때 덮어써지므로 지속적인 변경은 `src/`에 반영합니다.

GitHub Pages는 `main` 브랜치의 루트에서 배포합니다. 수정 후 빌드와 `node check-layout.cjs`, `node check-can.cjs`, `node check-workspace.cjs` 검사를 실행하고, 갱신된 `index.html`을 함께 커밋·푸시합니다.

## 현재 범위

- 영상 1: 중앙 시험 값 0–254, 140개 묶음 항목.
- 영상 2: 중앙 시험 값 0–31, 32개 개별 항목.
- 영상 3: 차로 설정과 불확실 상태 73개.
- 합계: 문구 143, 기본 표시 구간 27, 카메라 관찰 2, 차로 그래픽 68, 미확인 차로 항목 5.

같은 기본 화면이 이어지는 번호는 묶었습니다. 숫자 입력과 슬라이더로 각 시험 값을 선택할 수 있습니다.

이 패키지에는 원본 촬영 영상이 포함되지 않았습니다. 원문·번호를 새로 확인하려면 원본 영상 IMG_4952.mp4, IMG_4953.mp4, IMG_4955.mp4가 필요합니다. 기존의 판독 결과와 불확실성은 데이터에 포함되어 있습니다.
